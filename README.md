Aerokidz: A Lunar Survival Simulation
NASA Space Apps Challenge 2026 Submission
Welcome to Aerokidz! Specifically designed to inspire the next generation of space explorers, this 3D lunar survival and exploration experience is tailored for children aged 7 to 12. We built this project from the ground up during the hackathon to make historical space exploration interactive, educational, and deeply engaging for young minds.

Features & Kid-Friendly Gameplay
3D Lunar Exploration: Navigate a detailed, immersive lunar environment with intuitive, physics-based movement designed for younger players.
Interactive Mission Control: Approach and interact with 1:1 models of iconic space hardware, including the Apollo 11 Lunar Module and the Spitzer Space Telescope.
Educational Minigames: Engaging, custom-coded minigames triggered by proximity. These challenges task kids with simple equipment maintenance and survival puzzles that teach basic scientific concepts without feeling like homework.
Original UI & Audio: Includes a vibrant, fully functional Main Menu and thematic, inspiring background music to keep kids immersed in the adventure.

Technology Stack
Game Engine: Godot 4
Programming Language: C# (.NET)
IDE: Visual Studio Code
Version Control: Git & GitHub

This simulation is built for Windows Desktop and requires a physical keyboard for movement and interaction.
Download the provided Aerokidz_Build.zip file from our Google Drive submission link.
Right-click the downloaded ZIP file and select Extract All.
Open the extracted folder and double-click the Aerokidz.exe file to launch the simulation.
Use W, A, S, D or Arrow Keys to move the astronaut across the lunar surface.
Walk up to the Lunar Module or the Spitzer Space Telescope to trigger the interactive educational minigames!

Future Roadmap & Vision
While our hackathon submission serves as a functional Proof of Concept, we built Aerokidz with a scalable architecture to support future expansion. Our long-term vision for the simulation includes:
Accessibility for Visually Impaired Kids: Implementing robust spatial audio cues, sonar-based navigation feedback, and screen-reader compatibility so that blind and visually impaired children can fully experience the thrill of space exploration.
Global Localization: Adding multi-language support (starting with Spanish, Mandarin, and Malay) to make STEM education accessible to children worldwide, reflecting NASA's global mission.
Expanded Educational Curriculum: Introducing drivable lunar rovers, zero-gravity physics puzzles, and collectible database logs teaching lunar geology.
Enhanced Visual Fidelity: Upgrading real-time lighting systems, adding interactive lunar dust particle effects, and optimizing 3D models for deeper immersion.

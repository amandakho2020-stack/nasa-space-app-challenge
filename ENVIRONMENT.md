# Lunar Outpost: Moon Surface, Base Layout & Command Center

Everything here is generated by the **EnvironmentBuilder** node in `Main.tscn`, and it has already been applied to the scene.
To change something, select **EnvironmentBuilder**, edit its Inspector fields, click **Build Lunar Environment**, then press **Ctrl+S**.
Re-running replaces everything it generated: `LunarSurface`, `Base`, `LunarRover`, the environment and the Sun settings.

| File | What it is |
|---|---|
| `Scripts/EnvironmentBuilder.cs` | `[Tool]` entry point: Inspector settings, build order, environment, Sun, shared helpers |
| `Scripts/EnvironmentBuilder.Surface.cs` | Regolith material, carved craters, distant hills, MultiMesh rock scattering |
| `Scripts/EnvironmentBuilder.Base.cs` | Modular base: CSG shell, rooms, tubes, Rover Bay airlock, room interiors, pressurized zone |
| `Scripts/EnvironmentBuilder.Lobby.cs` | Command Center: desks, emissive screens, monitor bank, racks, base map, windows |
| `Scripts/EnvironmentBuilder.DrillSite.cs` | Remote outdoor Drill Site (~200 m south) and the marked rover road |
| `Scripts/EnvironmentBuilder.Rover.cs` | Apollo-scale lunar rover |
| `Scripts/LiveScreen.cs` | Fills screen text with live data (`{MET}`, `{O2}`, `{PWR}`, `{SOL}`, `{OBJ}`, …) |
| `Materials/*.tres`, `*.res` | Generated resources: regolith, environment, rock meshes, rock MultiMeshes |
| `Shaders/space_sky.gdshader` | Starfield sky. `Shaders/regolith.gdshader` is the optional custom-shader regolith. |

## 1. Lunar surface & rocks

### Node hierarchy

```
LunarSurface (Node3D)
├── Regolith (CSGBox3D 600 × 2 × 600, top at y = 0, Use Collision, material = regolith.tres)
│   ├── CraterBowl0..13 (CSGSphere3D, Operation = Subtraction, flattened: scale y = 0.28)
│   └── CraterRim0..13  (CSGTorus3D, flattened rim ring)
├── Hills (Node3D)
│   └── Hill0..19 (MeshInstance3D + SphereMesh, flattened, 215–285 m out: horizon)
└── Rocks (Node3D)
    ├── SmallRocks   → SmallRocks_Shape0..2   (MultiMeshInstance3D, ~900 rocks, 0.12–0.6 m)
    ├── MediumRocks  → MediumRocks_Shape0..2  (~180 rocks, 0.6–1.4 m)
    └── Boulders     → Boulders_Shape0..2     (~30 rocks, 1.6–4 m)
                     └── Colliders (StaticBody3D + one SphereShape3D per boulder)
```

### Regolith `StandardMaterial3D` (Inspector)

| Section | Property | Value |
|---|---|---|
| Albedo | Color | White |
| | Texture | **New NoiseTexture2D**: 1024², Seamless ON, Color Ramp = 3 grays (#3d3d3d → **#5a5a5a** → #7b7b7b), Noise = FastNoiseLite *Simplex Smooth*, Frequency 0.006, Fractal FBM, 5 octaves |
| Metallic | Metallic / **Specular** / Roughness | 0 / **0.0** / **1.0** |
| Normal Map | Enabled ON, Scale 1.0 | Texture = NoiseTexture2D 1024², Seamless, **As Normal Map ON, Bump Strength 10**, Simplex Smooth, Frequency 0.02, FBM **7 octaves** (fine rocky bumps) |
| Detail | Enabled ON, Blend Mode **Multiply**, UV Layer **UV1** | **Albedo** = grain noise (Simplex 0.09, 3 octaves, ramp gray 0.72 → white). **Normal** = **micro-craters**: NoiseTexture2D *As Normal Map*, Bump 3.5, FastNoiseLite **Cellular**, Distance Function *Euclidean Squared*, Return Type *Distance*, Frequency 0.012 |
| UV1 | **Triplanar ON, World Triplanar ON**, Scale (0.03, 0.03, 0.03), Sharpness 4 | One texture repeat every ~33 m; no UVs needed on CSG |
| Sampling | Filter | Linear Mipmap Anisotropic |

The builder's **Regolith Style = CustomShader** option switches to `Shaders/regolith.gdshader` instead (multi-scale world-space blending).

### Rock scattering

How the rocks are made:
- **Mesh:** a coarse `SphereMesh` (10 × 7 segments). Each vertex is pushed in or out by 3D FastNoiseLite FBM, the underside is flattened, and `SurfaceTool` rebuilds it with flat normals for faceted low-poly rocks. There are 3 shape variants, saved as `Materials/rock_mesh_*.res`.
- **Placement:**
  - Positions are uniform in a 190 m disc, thinned by a noise field so rocks gather in fields and streaks.
  - Sizes are skewed toward small rocks.
  - Each rock gets a random yaw and tilt, a non-uniform scale (flatter than wide), sinks slightly into the dust, and gets a per-instance gray tint (`MultiMesh.UseColors` + material *Vertex Color → Use As Albedo*).
- **Clear zones:** every room, tube, the Rover Bay pad and the solar field reserve their footprint plus `BaseClearMargin` (5 m). Rocks and craters are never placed there.
- **Collision:** only boulders get colliders (spheres), so the rover and player can't pass through them. Small rocks are visual only.

> Note for Victoria and the team: MultiMesh instance data is stored on the rendering server, so run the builder from the **editor**, not from a `--headless` command line, or the rock files save empty.

## 2. Airless lighting

**WorldEnvironment** (`Materials/lunar_environment.tres`):
- **Background:** Sky = `space_sky.gdshader` (static, non-twinkling stars, faint galactic band, hard sun disk), or Custom Color #000000 with *Use Starfield* off.
- **Ambient light:** source **Color**, **(0.02, 0.02, 0.024)**, which is effectively pitch black.
- **Reflected light:** Disabled.
- **Tonemap:** **ACES** (Godot 4's ACES is the fitted curve), Exposure 1.0.
- **Glow:** HDR threshold 2.5, so only screens, lamps and the sun disk bloom.
- **Fog:** off.

**Sun** (DirectionalLight3D):

| Property | Value |
|---|---|
| Rotation | (−20°, 150°, 0): low sun, long Apollo shadows |
| Energy | **6.0**: sunlit regolith washes out to white |
| Angular Distance | **0**: no PCSS penumbra, razor-sharp shadows |
| Shadow Opacity / Blur / Bias / Normal Bias | **1.0** / 0.25 / 0.04 / 1.0 |
| Directional Shadow | PSSM 4 Splits, Max Distance 150, Blend Splits ON |

**Project Settings** (already in `project.godot`): `directional_shadow/size = 8192`, `soft_shadow_filter_quality = Hard`.


Every floor is at **y = 0.25**. Each tube has 1.6 m inner radius, a flat walkway, a ceiling light strip, lamps every ~5 m, and direction signs at both ends.

### How the CSG shell works

All pressurized hulls are children of **one** `CSGCombiner3D` (`Base/Shell`, Use Collision ON), added in this order:

1. **Unions:** outer hulls (`*Hull`). Rooms are boxes or octagonal cylinders, tubes are cylinders rotated 90°, the Telescope is a cylinder plus a dome.
2. **Subtractions:** interior voids (`*Void`). Tubes run **centre to centre**, so wherever a tube void crosses a room wall, a round doorway appears automatically. Lobby window cuts, the drill roof hole, the telescope slit and the airlock opening are also subtractions.
3. **Unions after the voids:** floors (`*Floor`), tube walkways and light strips, so the voids don't carve them away.

To add a room: call `AddBoxRoom(...)` / `AddOctRoom(...)` and `AddTube(...)` in `BuildBaseLayout()`.

### How a screen is built (Inspector recipe)

1. **Bezel:** `CSGBox3D`, size (w + 0.06, h + 0.06, 0.03), near-black material.
2. **Panel:** `CSGBox3D`, size (w, h, 0.02). `StandardMaterial3D` with:
   - Albedo (0.01, 0.02, 0.02)
   - **Emission ON**, Emission color = phosphor green (0.25, 1, 0.45) or cyan (0.25, 0.9, 1) darkened 55%, Energy 0.6
   - Roughness 0.15
3. **Text:** `Label3D` child at z = +0.03:
   - Font Size 64, Pixel Size sized to fit (the builder computes it)
   - Modulate = the phosphor color lightened
   - Double Sided OFF, Horizontal Alignment Left
4. **Live data (optional):** attach `LiveScreen.cs` to the Label3D and write the text in **Template**, e.g. `MET: {MET}\nO2 {O2}%`.

The slanted desk screens use a basis whose +Z is the panel's outward normal (−0.8, 0.6) and whose +Y runs up the slope (0.6, 0.8), so the text lies flat on the panel.

## 5. Remote Drill Site

To move it, change **Drill Site Position** on the EnvironmentBuilder (Base group) and rebuild. The road is rebuilt to match.

- **Distance:** keep it 150–200 m from the base. At the default (13, 0, 200) it is ~180 m from the Rover Bay airlock.
- **Why the rover is needed:** the site has no pressurized shelter.
  - On foot (5 m/s) the trip takes ~35 s each way and drains ~35 O2. With the Sol 2 "skip exercise" penalty it's half speed, so double that.
  - The rover (12 m/s) takes ~16 s, and its life support stops the suit O2 drain while you drive (`GameManager.RoverSuppliesOxygen`).
- **Clear zones:** the site and road are kept free of rocks and craters, and hills are pushed back if they would overlap the site.
- **Navigation:** the HUD objective shows distance and compass direction to far-away consoles, e.g. "(181 m S)".

## 6. Lunar rover

The rover is a `VehicleBody3D` with Apollo LRV dimensions:
- 2.3 m wheelbase, 1.8 m track, 0.41 m wheel radius
- Gravity scale 0.165 (lunar gravity), center of mass (0, −0.6, 0)

It is parked on the Rover Bay pad at (13, 21) with its nose pointing **south (+Z)**, out along the road.

### Controls and the "forward" convention

Godot's `VehicleBody3D` drives along local **+Z**: a positive `EngineForce` pushes toward +Z. A positive `Steering` angle turns toward local +X, which is the driver's **left**.
The rover's visual front (dash, antennas, forward box) is built on +Z to match. If an imported model faces −Z (Godot's usual "forward"), rotate the model 180° under the rover rather than changing the code.

| Key | Effect (`RoverController.cs`) |
|---|---|
| W | `EngineForce = +ForwardEngineForce` (220 N per wheel) up to 12 m/s; if rolling backwards it brakes first |
| S | Brakes while moving forward (> 0.6 m/s), then `EngineForce = −ReverseEngineForce` up to 4 m/s reverse |
| A / D | `Steering` toward +/− `MaxSteerRadians` (0.5 rad), reduced to 35 % at top speed |
| Space | Handbrake |
| Mouse | Look around; the camera swings back behind the rover 1.2 s after you stop moving the mouse, and resets on boarding |
| E | Exit (only below 2 m/s) |

**Stability assist:** in 1/6 g the tyres carry very little weight, so a pure-physics rover rolls over easily.
- A spring-damper torque keeps the chassis upright: `UprightStiffness` 6, `UprightDamping` 2.5. It acts on roll and pitch only.
- If the rover still ends up on its side for 1.5 s, it is set back on its wheels.
- Set both values to 0 for pure simulation.

**Why it felt inverted before:** the rover used to be parked facing the base, so W drove into the airlock, and the chase camera kept any mouse orbit forever, so the camera could end up in front of the rover. Both are fixed: the rover now parks facing out and the camera recenters.

**Scale reference:** set **Rover = StationaryScaleReference** and rebuild for a static CSG-only version to match against an imported model.
